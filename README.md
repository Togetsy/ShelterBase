
# ShelterAccounting

## 1. О проекте

**ShelterAccounting** — информационная система для автоматизации учёта животных, находящихся на содержании в приюте.

Система обеспечивает централизованное хранение, обработку и актуализацию сведений о животных, включая их вид, пол, кличку, возраст, состояние и текущий статус.

Основные задачи системы:

- Хранение информации о животных и их характеристиках.
- Добавление новых записей и обновление существующих.
- Связывание информации о животных с их статусами.
- Поиск и фильтрация по виду, возрасту, полу, кличке и статусу.
- Управление данными в соответствии с правами доступа.
- Учёт пристройства животных и сохранение информации о новых владельцах.

## 3. Пользователи системы

В системе предусмотрены две роли:

| Роль | Права и возможности |
|---|---|
| **Администратор приюта** | Добавление, редактирование и удаление записей о животных, изменение статусов и сведений о состоянии, оформление пристройства |
| **Сотрудник приюта** | Авторизация, поиск животных, просмотр списка и информации о выбранном животном |

## 4. Основной функционал

### 4.1. Учёт животных

- Регистрация нового животного и создание его карточки.
- Редактирование и актуализация сведений.
- Удаление записи или архивация животного.

### 4.2. Управление статусами

- Изменение текущего статуса животного.
- Обновление сведений о состоянии.
- Фиксация факта пристройства.

### 4.3. Поиск и фильтрация

- Поиск животных по виду, возрасту, полу и статусу.
- Поиск по кличке.
- Формирование списков по выбранным параметрам.

### 4.4. Пристройство животных

- Проверка возможности пристройства выбранного животного.
- Сохранение информации о новом владельце.
- Изменение статуса животного после оформления пристройства.

## 5. Архитектура проекта

Система проектируется на основе **трёхуровневой архитектуры**.

- **Слой представления** — взаимодействие с пользователем через графический или консольный интерфейс, отображение списков и форм, первичная проверка вводимых данных.
- **Слой бизнес-логики** — реализация правил предметной области, проверка обязательных полей, прав доступа и корректности изменения статусов.
- **Слой данных** — доступ к базе данных, выборка, добавление, обновление и удаление записей, обеспечение целостности связей и хранение информации.

## 6. Установка

Для работы с проектом потребуется Python

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Togetsy/ShelterBase.git
   ```

2. Перейдите в каталог проекта:

   ```bash
   cd ShelterBase
   ```

3. Откройте папку проекта в среде разработки.
4. Установите необходимые зависимости, если они предусмотрены проектом.
