# ShelterAccounting

## О проекте

**ShelterAccounting** — информационная система для автоматизации учёта животных в приюте.

Программа предназначена для централизованного хранения и обработки информации о животных: вида, пола, клички, состояния и текущего статуса.

Она позволяет:
- хранить информацию о животных в единой базе данных;
- добавлять и изменять сведения о животных;
- отслеживать текущий статус и состояние животных;
- быстро находить нужную информацию с помощью поиска и фильтрации;
- хранить информацию о пристройстве животных.

## Пользователи системы

В программе предусмотрены две роли:

 **Администратор**  Добавление, изменение и удаление информации о животных, управление статусами, оформление пристройства 
 **Сотрудник**  Поиск и просмотр информации о животных 

## Основные возможности

- регистрация животных;
- редактирование информации;
- снятие животных с учёта;
- изменение статуса и сведений о состоянии;
- поиск и фильтрация по виду, возрасту, полу, кличке и статусу;
- оформление пристройства;
- сохранение информации о новом владельце.
